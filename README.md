# .github

Org-wide default files for JMNZ-Technologies — automatically inherited by any repo in the org that doesn't define its own copy of the same file.

See [GitHub's docs on default files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for how this repo is picked up.

**Must stay public.** Private `.github` repos don't serve any org-wide defaults at all — confirmed against GitHub's docs. If this repo is ever flipped back to private, none of the above applies anywhere until it's public again.
