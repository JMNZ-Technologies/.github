# Security Policy

All repositories in JMNZ-Technologies are private. To report a vulnerability, use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on the affected repository (Security tab → Report a vulnerability), or contact @aleixjf directly.

Please do not open a public issue for security reports.
